### Git and GitHub Commands I Learned Today

1. `git add .` – Adds all changes to the staging area.
2. `git commit -m "message"` – Saves changes with a descriptive commit message.
3. `git push` – Uploads local commits to a remote GitHub repository.
4. `git clone` – Copies a remote repository to my local computer.
5. `git fork` – Creates my own copy of someone else's GitHub repository.
